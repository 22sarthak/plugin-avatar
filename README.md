# Avatar Platform

Reusable, free-first, photo-assisted 3D avatar platform scaffold.

This repository intentionally keeps external reference repositories in `external/` only. Product code in `apps/`, `packages/`, `services/`, and `assets/` is a clean implementation.

## Commands

```sh
pnpm install
pnpm dev:studio
pnpm dev:demo
pnpm dev:api
pnpm typecheck
pnpm build
```

## Local URLs

- Studio: http://localhost:5173
- Demo site: http://localhost:5174
- API health: http://localhost:4000/health

See `docs/LOCAL_DEVELOPMENT.md` for the full local workflow.
